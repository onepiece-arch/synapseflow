# ⚡ SynapseFlow OS — Unified All-in-One SaaS Platform

> **The Unified Cloud Productivity & Academic Suite**  
> Built with **100% Astro.js (Astro 5)**, **Tailwind CSS**, and modern Glassmorphic Dark UI.

---

## 🚀 Overview

**SynapseFlow OS** unifies four previously disparate projects into a single, cohesive, high-performance SaaS dashboard:

1. **📄 PDF Power Studio (`/pdf-tools`)**:
   - 7 Core Tools: Multi-file Merge, Visual Page-Range Split, Smart Vector Compression, Institutional Watermark & Stamps, AI Watermark Remover, Custom Page Numbering, and OCR Text Extractor.
2. **🎯 ATS Resume Intelligence AI (`/ats-checker`)**:
   - Live ATS Compatibility Score (0-100), Keyword Match Rate (Matched vs Missing skills), Power Action Verbs Analyzer, Measurable Impact Tracker, and 1-Click AI Prompt Generator for ChatGPT/Claude.
3. **📋 Campus Attendance System (`/attendance`)**:
   - Multi-course switcher (CS-301, CS-302, AI-401, CS-405), Real-time live dynamic attendance KPI counters, 1-Click batch actions (Mark All Present, Absent), Low attendance alerts (<75%), and CSV/Excel/PDF export.
4. **📚 Faculty Academic Diary (`/faculty-diary`)**:
   - Interactive Weekly Timetable, Syllabus Completion Progress Tracker with interactive module checklists, Student Mentorship & Remarks Log, Course Material Cloud Repository, and Research Papers & Grants Monitor.
5. **⚡ Unified Command Center (`/dashboard`)**:
   - High-impact KPI stat cards, Quick Workspace Launchers, Live Activity Stream, and Instant Dropzone Sandboxes.
6. **📈 Unified Analytics & Insights (`/analytics`)**:
   - Cross-product telemetry, document I/O volumes, and course attendance distributions.
7. **⚙️ Workspace Settings (`/settings`)**:
   - User profile settings, color accent customization, and API integration tokens.
8. **🌐 Public SaaS Landing Page (`/`)**:
   - High-converting modern SaaS hero, live interactive feature sandbox, pricing tiers, and FAQ.

---

## 🛠️ Tech Stack & Styling

- **Framework**: [Astro 5.x](https://astro.build/) (Static Site Generation & Client Island Scripts)
- **Styling**: Tailwind CSS with custom Glassmorphism (`.glass-panel`, `.glass-card`, `.btn-gradient`, `.shadow-glow-*`, `.gradient-text`)
- **Typography**: Plus Jakarta Sans & JetBrains Mono
- **Interactivity**: Vanilla Client-Side JavaScript with zero runtime framework overhead

## 💻 Getting Started

```bash
# Navigate to the combined project
cd "combine-saas"

# Install dependencies (if not already installed)
npm install

# Start development server on port 4321
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
